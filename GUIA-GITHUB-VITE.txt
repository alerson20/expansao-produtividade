PROJETO PRONTO PARA VITE + GITHUB PAGES

1. Instale Node.js LTS e Git.
2. Abra o PowerShell dentro desta pasta.
3. Execute: npm install
4. Execute: npm run dev
5. Crie um repositório público no GitHub.
6. Execute os comandos Git indicados no tutorial fornecido no ChatGPT.
7. No GitHub, abra Settings > Pages e selecione GitHub Actions.
8. Faça push para a branch main. O workflow publicará automaticamente.

A configuração do Vite detecta automaticamente o nome do repositório no GitHub Pages.
