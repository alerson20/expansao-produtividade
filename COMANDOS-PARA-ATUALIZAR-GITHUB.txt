COMANDOS PARA PUBLICAR A NOVA VERSÃO
====================================

Abra o PowerShell na pasta do projeto e execute:

npm.cmd install
npm.cmd run build
git add .
git commit -m "Troca FormSubmit por envio via Google Apps Script"
git push

Depois abra o GitHub > Actions e aguarde a publicação ficar verde.
Site: https://alerson20.github.io/expansao-produtividade/
Pressione Ctrl + F5 para limpar o cache.
