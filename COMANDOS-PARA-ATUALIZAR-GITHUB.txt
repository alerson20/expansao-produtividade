COMANDOS PARA ATUALIZAR O SITE NO GITHUB

1. Copie todos os arquivos desta pasta para:
   C:\Users\Alerson\Desktop\landing_ebook_expansao

2. Confirme a substituição dos arquivos antigos.

3. Abra o PowerShell nessa pasta e execute, um por vez:

npm.cmd install
npm.cmd run build
git add .
git commit -m "Corrige formulario, sucesso e envio do ebook por email"
git push

4. Acompanhe em:
   GitHub > expansao-produtividade > Actions

5. Quando ficar verde, abra:
   https://alerson20.github.io/expansao-produtividade/

6. Pressione Ctrl + F5 ou use uma janela anônima.

7. Faça a ativação descrita no arquivo ATIVAR-FORMULARIO-EMAIL.txt.
